# DeepCLAW Discord Extension

Discord channel adapter for DeepCLAW.

## Features

- Discord gateway integration
- Message and interaction handling
- RBAC permission enforcement
- Audit logging

## Installation

```bash
pip install deepclaw[discord]
```

## Configuration

```python
from deepclaw.channels.adapters import DiscordChannel

channel = DiscordChannel(bot_token="YOUR_BOT_TOKEN")
```
