# Security Policy

## Reporting a Vulnerability

**SILICON VALLEY GLOBAL PH INC** ([https://svg.ph](https://svg.ph)) takes the security of DeepCLAW seriously.

If you discover a potential security vulnerability in DeepCLAW, please report it privately to our team before public disclosure.

- **Contact Email:** opensource@svg.ph
- **Company Website:** [https://svg.ph](https://svg.ph)
- **Response Time:** We will acknowledge receipt within 24 hours and provide an estimated resolution timeline.

Please do not open public GitHub issues for security vulnerabilities.
